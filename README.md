Data Professional Survey Dashboard

About the Project

I built this Power BI dashboard to explore a survey dataset containing responses from people working in the data field. The goal was to turn the raw survey data into an interactive dashboard that makes it easier to understand salary trends, job roles, job satisfaction, and work-life balance.

Instead of looking at the data through raw tables, the dashboard brings the important information together through interactive charts, KPIs, and filters.

Tools & Technologies

* Power BI
* Power Query
* DAX

What I Analyzed

The dashboard focuses on areas such as:

* Salary differences across data-related job roles
* Job satisfaction among respondents
* Work-life balance
* Distribution of respondents across different job roles
* Geographic distribution of survey participants
* Salary trends across different roles
* Other patterns and trends within the survey data

 What I Built

* Cleaned and transformed the raw survey data using Power Query
* Created calculated measures using DAX
* Designed interactive visualizations and KPI cards
* Added slicers to allow users to explore the data based on different categories
* Organized the dashboard to present the most useful insights clearly
* Used Power BI to turn the survey data into an interactive business intelligence report

 What I Learned

Through this project, I gained practical experience in working with Power BI and learned how to:

* Prepare and transform real-world datasets
* Build meaningful visualizations
* Create DAX measures
* Design interactive dashboards
* Explore relationships and trends within data
* Present analytical findings in a simple and understandable way

 Project Outcome

The final dashboard provides an interactive way to explore the experiences and characteristics of data professionals. It helped me understand how raw survey data can be transformed into a visual report that can support data-driven analysis and decision-making.
